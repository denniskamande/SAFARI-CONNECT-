# 🚌 Safari Connect — Transport Data Analytics Project

## 📌 Project Overview

Safari Connect is a transport data analytics project focused on transforming raw booking data into clean, structured, and business-ready insights.

The project follows a data analytics workflow using **PostgreSQL, SQL, and Power BI**, starting with raw and inconsistent booking data, cleaning and transforming it, performing business analysis, and finally presenting the results through an interactive Power BI dashboard.

The project demonstrates practical skills in SQL data cleaning, data transformation, analysis, window functions, CTEs, views, indexing, DAX, and data visualization.

---

## 🎯 Project Objectives

The main objectives of this project were to:

- Clean and standardize raw transportation booking data.
- Identify and resolve data quality issues.
- Analyse booking, revenue, route, passenger, driver, and vehicle performance.
- Investigate cancellations, no-shows, and lost revenue.
- Create reusable SQL views for BI reporting.
- Improve database query performance using indexes.
- Build an interactive Power BI dashboard.
- Translate data into actionable business recommendations.
